# 王廷明醫師個人網頁

> 臺大醫院骨科部主任．國立台灣大學醫學院骨科教授

## 網站功能

- **醫師介紹**：完整學經歷、現任職務、專科執照（分頁切換）
- **衛教影片中心**：整合 5 部「手術善其事」系列衛教影片
  - 髖關節系列：受損原因、截骨矯正手術
  - 膝關節系列：受損辨識、保膝手術 Q&A、人工膝關節置換
- **互動式理解測驗**：4 題理解測驗，看完影片後驗證重點觀念
- **健保 vs 自費比較**：人工關節材料差異一覽表
- **就診指引**：初診流程、掛號額滿處理、轉診流程、手術安排
- **聯絡管道**：LINE 官方帳號、臺大醫院掛號、官方介紹頁

## 設計理念

1. **看診前過濾**：透過衛教影片與測驗，提前教育病人，節省門診時間
2. **互動式分流**：答對才能進入預約流程，初步篩選病人
3. **品牌累積**：屬於王醫師個人的數位資產，為未來職涯轉型累積病患基礎
